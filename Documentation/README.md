# Benchmark de Algoritmos de Ordenação

Análise comparativa de desempenho entre **Quick Sort**, **Heap Sort** e **Radix Sort** desenvolvida em Python.

## Estrutura do projeto

* `sorting.py`: Roda o benchmark de ordenação.
* `plotting.py`: Gera os gráficos usados no artigo.
* `benchmark\_results.csv`: Resultados das medições (tempo, memória, trocas e comparações).
* `main.tex`: Artigo em LaTeX formatado.

## Como rodar

```bash
# Dependências
pip install pandas matplotlib seaborn

# Execução
python sorting.py
python plotting.py
```
